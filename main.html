GitHub Pages Deployment Guide

How to make your site live for free

1

Create a GitHub Repository

Go to GitHub.com, log in, click the "+" button, and choose New repository. Name it carmen-portfolio.

2

Upload index.html

Save this exact file on your laptop as index.html. In your new repository page, click "uploading an existing file", drag index.html into GitHub, and click Commit changes.

3

Turn On GitHub Pages

Go to Settings > Pages inside your repository. Under Branch, select main and click Save.

4

Your Live Link

After about 1–2 minutes, your website will be live at https://<your-username>.github.io/carmen-portfolio/.

Adding Projects Instructions

1. Open index.html in VS Code or Notepad.

2. Scroll down to the <div id="projectsContainer"> section.

3. Delete <!-- before and --> after the template card snippets to make them appear!

4. Replace the title, description, and link URLs with your own project info.
